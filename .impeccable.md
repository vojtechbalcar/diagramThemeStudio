## Design Context

### Users
Designers and developers turning a brand's design tokens into Mermaid themes. They need to compare four diagram types, inspect contrast and export a reusable configuration without an account or backend.

### Brand Personality
Precise, clear, restrained. The graphics standards manual in `design.md` is binding: information first, mixed-case plain language, consistent sign panels and bands.

### Aesthetic Direction
A working graphics manual informed by Unimark's transit-sign methodology. Achromatic interface, Inter and JetBrains Mono, square corners, ruled frames and numbered bullets. User colours appear only in token bullets, diagrams and the palette strip. Light/dark interface is independent of preview surfaces.

### Design Principles
- Make theme judgment and export the purpose of every element.
- Use the existing 4px spacing and fixed type scales, semantic ink scopes and closed symbol set.
- Convey contrast by shape, number and text; keep keyboard focus visible.
- Keep motion finite and explanatory; stop the landing cycle for reduced motion, hover and focus.
- Adapt workflows for phones without removing controls.
