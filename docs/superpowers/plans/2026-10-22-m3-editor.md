# M3 editor implementation plan

**Goal:** Complete the editor v1 in `CLAUDE.md` milestone 3, using `design.md` as the approved visual specification.

**Architecture:** A serialisable `TokenSet` reducer owns tokens, mappings, name and surface. A client editor connects the existing system components to it. One dynamically loaded Mermaid adapter serialises entire render batches and returns resolved theme variables alongside per-diagram results. Contrast uses those resolved colours, including derived values.

**Tech stack:** Next.js 16 App Router, React 19, TypeScript, Radix, Mermaid 11, Vitest, Playwright.

The user requested continuing M3 and committing/pushing each finished feature. Execute inline on `m3-editor`; preserve the unfinished parser cleanup. M4 export/share and M5 focus mode/landing-page work stay out of scope.
